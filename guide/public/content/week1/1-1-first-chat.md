# Claude 소개 및 첫 대화

> [!TIP]
> 이 실습에서는 **claude.ai**에 접속해 첫 대화를 시작합니다. 역할과 형식을 지정한 프롬프트로 **여행 일정표**를 만들고, 추가 대화로 결과를 바꿔 봅니다.

> [!CONCEPT] Claude는 어떤 AI인가요?
>
> Claude는 Anthropic이 만든 대화형 생성형 AI입니다.
>
> - **긴 문맥 이해력**: 수백 페이지 PDF와 보고서를 한 번에 분석합니다
> - **자연스러운 한국어**: 번역투 없이 매끄러운 실무 문서를 작성합니다
> - **안전성과 코딩 역량**: 근거 없는 추측을 줄이고 정확한 코드를 만듭니다

## 태스크 1: Claude 접속과 화면 둘러보기

1. 브라우저에서 [claude.ai](https://claude.ai)에 접속해 로그인합니다.
2. 화면 구성을 확인합니다.

| 위치 | 기능 | 언제 쓰나요? |
|---|---|---|
| 왼쪽 메뉴 | 새 채팅 · Projects · 기록 | 주제가 바뀌면 **새 채팅**을 엽니다 |
| 입력창 아래 | 모델 선택 (Sonnet / Haiku / Opus) | 일상 업무는 **Sonnet** 권장 |
| 입력창 왼쪽 | 📎 파일 첨부 · 웹 검색 | PDF·엑셀·사진을 끌어다 놓아 업로드 |

> [!NOTE]
> Opus는 유료 요금제에서 사용할 수 있습니다. 오늘 실습은 무료 계정의 기본 모델로도 충분합니다.

## 태스크 2: 실습 A — 여행 일정 자동 생성

아래 프롬프트를 복사해 입력창에 붙여 넣고 **Enter**를 누릅니다.

```text
당신은 친절한 여행 전문가입니다. 서울에서 출발하는 1박 2일 여행 일정을 작성해주세요. 시간표와 예상 비용을 표로 정리하고 초보 여행자도 쉽게 이해할 수 있게 설명해주세요.
```

> [!SUCCESS]
> 결과에서 다음 세 가지를 확인하세요.
> - **역할 반영**: 친절한 여행 전문가 말투인가요?
> - **표 형식**: 시간표와 비용이 표로 정리되었나요?
> - **초보자 눈높이**: 설명이 쉽게 쓰였나요?

## 태스크 3: 추가 대화로 결과 바꾸기

같은 대화창에서 이어서 요청합니다. Claude는 앞의 대화를 기억합니다.

```text
강릉으로 바꿔줘
```

```text
예산을 1인 15만 원 이내로 맞춰서 다시 정리해줘
```

> [!TIP]
> 원하는 결과가 나올 때까지 **짧게 여러 번** 고쳐 달라고 하는 것이 한 번에 길게 쓰는 것보다 효과적입니다.

## 태스크 4: Claude와 ChatGPT, 언제 무엇을 쓸까?

| 활용 영역 | Claude | ChatGPT |
|---|---|---|
| 문서·글쓰기 | 자연스러운 문체, 긴 문서 정밀 요약 | 아이디어 브레인스토밍, 다양한 톤 |
| 코딩·웹앱 | Artifacts 실시간 실행, Claude Code | Canvas 편집, 코드 인터프리터 |
| 업무 지식 고정 | Projects (문서 + 지침 전용 공간) | Custom GPTs, 프로젝트 폴더 |
| 멀티미디어 | SVG 다이어그램, 인터랙티브 차트 | 사진형 이미지, 음성 대화 |

두 도구는 경쟁이 아니라 **보완 관계**입니다. 문서·분석·웹앱 자동화에는 Claude가 잘 맞습니다.
