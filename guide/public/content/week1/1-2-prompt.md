# 프롬프트 작성법

> [!TIP]
> 같은 질문도 **어떻게 묻느냐**에 따라 결과가 크게 달라집니다. 5가지 요소를 넣은 프롬프트와 단순 질문의 결과를 직접 비교합니다.

> [!CONCEPT] 좋은 프롬프트의 5가지 요소
>
> - **① 역할**: AI의 전문가 페르소나를 지정합니다 (예: 10년 차 마케터)
> - **② 목적**: 원하는 최종 결과물을 밝힙니다 (예: 출시 안내 메일)
> - **③ 맥락**: 대상·배경·상황을 알려 줍니다 (예: 30대 직장인, 텀블러 신제품)
> - **④ 형식**: 표·목록·이메일 등 구조를 정합니다 (예: 3문단)
> - **⑤ 제약조건**: 분량·금지 사항·어조를 정합니다 (예: 친근한 어조)

## 태스크 1: BEFORE — 단순 질문

새 채팅을 열고 입력합니다.

```text
신제품 홍보 이메일 써줘.
```

## 태스크 2: AFTER — 5요소 적용 질문

**새 채팅**을 하나 더 열고 입력합니다. 앞 대화의 영향을 받지 않게 하기 위해서입니다.

```text
10년 차 마케터로서 30대 직장인 대상 텀블러 출시 메일을 3문단, 친근한 어조로 작성해줘.
```

## 태스크 3: 결과 비교하기

| 비교 항목 | BEFORE (단순 질문) | AFTER (5요소 적용) |
|---|---|---|
| 내용 | 뻔하고 일반적인 문구 | 타깃 맞춤형 제목 제안 |
| 정보 | 제품 특성·고객 대상 누락 | 핵심 혜택 중심의 3단 구성 |
| 활용도 | 바로 보내기 어려운 초안 | 바로 실무에 쓰는 완성도 |

> [!SUCCESS]
> 두 결과를 나란히 놓고, AFTER에서 5요소가 각각 어디에 반영되었는지 찾아보세요.

## 태스크 4: 나만의 프롬프트 만들기

아래 틀의 빈칸을 내 업무로 채워 입력해 보세요.

```text
당신은 [역할]입니다.
[대상/상황]을 위해 [만들 결과물]을 작성해주세요.
형식: [표 / 목록 / 이메일 / 보고서]
조건: [분량], [어조], [꼭 넣을 내용 또는 빼야 할 내용]
```

> [!TIP]
> 결과가 마음에 들지 않으면 처음부터 다시 쓰지 말고 "더 짧게", "표로 바꿔줘", "숫자 근거를 넣어줘"처럼 **한 가지씩** 고쳐 달라고 하세요.
