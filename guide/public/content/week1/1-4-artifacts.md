# Artifacts 도구 제작

> [!TIP]
> 코드를 몰라도 대화 한 줄로 **바로 실행되는 퀴즈 앱**을 만듭니다. 1차 결과를 확인한 뒤 후속 프롬프트로 진행률 막대, 해설, 다시 풀기 버튼을 더합니다.

> [!CONCEPT] Artifacts란?
>
> 대화창 오른쪽에 결과물을 **바로 실행해 보여 주는 창**입니다.
>
> - **왼쪽 대화창**: 자연어로 디자인과 기능을 수정합니다
> - **오른쪽 실행 창**: 미리보기 · 코드 · 링크 공유를 할 수 있습니다

## 태스크 1: 실습 C — 퀴즈 만들기

```text
일반인이 사용할 수 있는 5문제짜리 AI 상식 퀴즈를 만들어주세요. 각 문항에 선택지 4개와 정답 확인 버튼을 넣고, 마지막에 총점을 보여주세요.
```

> [!NOTE]
> 오른쪽에 실행 창이 열리지 않으면 "Artifacts로 실행할 수 있게 만들어줘"라고 한 번 더 요청하세요.

## 태스크 2: 동작 확인 3단계

| 단계 | 확인할 것 |
|---|---|
| 문항 구성 | 5문제 × 4지선다가 정상으로 보이나요? |
| 정답 피드백 | 정답 확인을 누르면 채점이 되나요? |
| 총점 화면 | 5문제를 다 풀면 점수가 나오나요? |

## 태스크 3: 반복 개선하기

1차 결과에서 아쉬운 점을 하나씩 고쳐 달라고 요청합니다. 한 번에 하나씩 보내세요.

```text
상단에 진행률 막대를 추가해줘
```

```text
정답 확인 시 쉬운 한 줄 해설 표시해줘
```

```text
남색·주황 테마와 다시 풀기 버튼 넣어줘
```
