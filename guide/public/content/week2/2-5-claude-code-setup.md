# Claude Code 개요 및 환경 세팅

> [!TIP]
> 오후에는 **Claude Code**로 내 컴퓨터에서 직접 파일을 만들고 고칩니다. 이번 교시에서는 개념을 잡고, VS Code 터미널에서 Claude Code를 처음 실행합니다.

> [!CONCEPT] Claude Code란?
>
> 자연어로 지시하면 **내 컴퓨터에서 직접 파일을 만들고 수정하는 AI 에이전트**입니다.
>
> - **직접 파일 생성**: 복사·붙여넣기 없이 프로젝트 폴더에 자동 저장합니다
> - **전체 맥락 파악**: 여러 코드 파일을 동시에 읽고 고칩니다
> - **오류 자동 해결**: 에러 메시지를 읽고 원인을 찾아 고칩니다

## 태스크 1: Claude Chat과 Claude Code 비교

| 구분 | Claude Chat (웹·앱) | Claude Code (터미널·IDE) |
|---|---|---|
| 성격 | 대화형 AI 비서 | 실행형 코딩 에이전트 |
| 실행 위치 | 웹 브라우저 (claude.ai) | 내 PC 터미널 / VS Code |
| 주요 작업 | 글쓰기·요약·아이디어·Artifacts | 웹앱 제작·여러 파일 수정·디버깅 |
| 파일 반영 | 사용자가 직접 복사·저장 | 승인 후 폴더에 자동 생성·수정 |
| 요금 | 무료(Free)부터 시작 | 유료(Pro 이상) 또는 API 키 필요 |

## 태스크 2: 웹앱은 어떻게 작동할까?

| 순서 | 구성 | 식당 비유 |
|---|---|---|
| 1. 브라우저 | 크롬 등 웹앱 실행 창 | 손님이 들어오는 문 |
| 2. 화면 (UI) | 입력창·버튼·표시 영역 | **홀** — 손님이 보고 주문하는 곳 (프론트엔드) |
| 3. 로직 | 입력 검증·계산·결과 처리 | **주방** — 주문을 처리하는 곳 (백엔드) |
| 4. 데이터 | 결과 기록·저장·내보내기 | **창고** — 재료와 기록을 보관 (데이터베이스) |

> [!NOTE]
> 오늘 만드는 웹앱은 **프론트엔드(홀)**만으로 동작합니다. 서버 없이 브라우저에서 바로 실행됩니다.

## 태스크 3: 요금제와 준비물 확인

| 요금제 | 월 요금 (USD) | Claude Code | 권장 대상 |
|---|---|---|---|
| Free | $0 | 미포함 (Chat·Artifacts 가능) | AI 입문 체험 |
| Pro | $20/월 (연간 결제 시 $17) | 포함 (기본 사용량) | 개인 실무·입문 코딩 |
| Max | $100 / $200 | 포함 (Pro 대비 5~20배) | 집중 개발·대량 작업 |
| API (종량제) | 사용량 비례 | 지원 (API 키 연동) | 개발자·자동화 |

> [!IMPORTANT]
> 요금과 사용량은 바뀔 수 있습니다. 수업 전에 [claude.com/pricing](https://claude.com/pricing)에서 최신 정보를 확인하세요.

**사전 준비물:**
- [VS Code](https://code.visualstudio.com/) 설치
- [Node.js](https://nodejs.org/) LTS 버전 설치

> [!TIP]
> 설치에 실패했거나 무료 계정이면 강사 시연을 보면서 **Claude Chat + Artifacts**로 같은 실습을 진행합니다. 각 교시에 Chat용 방법도 함께 적어 두었습니다.

## 태스크 4: 개발 환경 열고 첫 명령 실행

1. 바탕화면에 `my-first-app` 폴더를 만듭니다.
2. VS Code에서 **파일 → 폴더 열기**로 이 폴더를 엽니다.
3. **Ctrl + `** (백틱)으로 터미널을 엽니다.
4. Claude Code를 설치하고 실행합니다.

```bash
npm install -g @anthropic-ai/claude-code
claude
```

5. 처음 실행하면 로그인 화면이 나옵니다. 안내에 따라 Claude 계정으로 로그인합니다.
6. 첫 명령을 입력합니다.

```text
안녕! 현재 폴더 상태를 확인해줘.
```

> [!OUTPUT]
> ```
> ✓ 현재 폴더(my-first-app)는 비어 있습니다.
>   무엇을 만들어 드릴까요?
> ```

> [!WARNING]
> Claude Code가 파일을 만들거나 고치기 전에 **허용(Yes)** 여부를 묻습니다. 무엇을 바꾸는지 읽어 본 뒤 허용하세요.
