# Claude Code 개요 및 환경 세팅

> [!TIP]
> 오후에는 **Claude Code**로 내 컴퓨터에서 직접 파일을 만들고 고칩니다. **VS Code나 터미널은 열지 않습니다.** Claude 데스크톱 앱 하나에서 폴더만 고르면 바로 시작할 수 있습니다.

> [!CONCEPT] Claude Code란?
>
> 자연어로 지시하면 **내 컴퓨터에서 직접 파일을 만들고 수정하는 AI 에이전트**입니다.
>
> - **직접 파일 생성**: 복사·붙여넣기 없이 작업 폴더에 자동 저장합니다
> - **전체 맥락 파악**: 여러 파일을 동시에 읽고 고칩니다
> - **오류 자동 해결**: 증상을 설명하면 원인을 찾아 고칩니다

## 태스크 1: Claude Chat과 Claude Code 비교

| 구분 | Claude Chat | Claude Code |
|---|---|---|
| 성격 | 대화형 AI 비서 | 실행형 코딩 에이전트 |
| 사용하는 곳 | claude.ai 또는 데스크톱 앱의 **Chat** | 데스크톱 앱의 **Code** 탭 |
| 주요 작업 | 글쓰기·요약·아이디어·Artifacts | 웹앱 제작·여러 파일 수정·디버깅 |
| 파일 반영 | 사용자가 직접 복사·저장 | 허용하면 내 폴더에 자동 생성·수정 |
| 요금 | 무료(Free)부터 시작 | 유료(Pro 이상) 필요 |

> [!NOTE]
> 같은 앱 안에서 대화창만 바뀝니다. 오전에 쓰던 Chat과 화면이 비슷해서 따로 익힐 것이 거의 없습니다.

## 태스크 2: 웹앱은 어떻게 작동할까?

| 순서 | 구성 | 식당 비유 |
|---|---|---|
| 1. 브라우저 | 크롬 등 웹앱 실행 창 | 손님이 들어오는 문 |
| 2. 화면 (UI) | 입력창·버튼·표시 영역 | **홀** — 손님이 보고 주문하는 곳 (프론트엔드) |
| 3. 로직 | 입력 검증·계산·결과 처리 | **주방** — 주문을 처리하는 곳 (백엔드) |
| 4. 데이터 | 결과 기록·저장·내보내기 | **창고** — 재료와 기록을 보관 (데이터베이스) |

> [!NOTE]
> 오늘 만드는 웹앱은 **프론트엔드(홀)**만으로 동작합니다. 서버 없이 브라우저에서 바로 실행됩니다.

## 태스크 3: 요금제와 준비물 확인

| 요금제 | 월 요금 (USD) | Claude Code | 권장 대상 |
|---|---|---|---|
| Free | $0 | 미포함 (Chat·Artifacts 가능) | AI 입문 체험 |
| Pro | $20/월 (연간 결제 시 $17) | 포함 (기본 사용량) | 개인 실무·입문 코딩 |
| Max | $100 / $200 | 포함 (Pro 대비 5배 / 20배) | 집중 개발·대량 작업 |

> [!IMPORTANT]
> 요금과 사용량은 바뀔 수 있습니다. 수업 전에 [claude.com/pricing](https://claude.com/pricing)에서 최신 정보를 확인하세요.

**준비물은 하나뿐입니다.**
- [Claude 데스크톱 앱](https://claude.com/download) (Windows · Mac) 설치 후 Pro 이상 계정으로 로그인

> [!TIP]
> 무료 계정이거나 앱을 설치할 수 없으면 강사 시연을 보면서 **Claude Chat + Artifacts**로 같은 실습을 진행합니다. 각 교시에 Chat용 방법도 함께 적어 두었습니다.

## 태스크 4: Code 탭 열고 첫 지시 내리기

1. 바탕화면에 `my-first-app` 폴더를 새로 만듭니다.
2. Claude 데스크톱 앱을 열고 화면 위쪽(또는 왼쪽)의 **Code** 탭을 누릅니다.
3. 작업 폴더를 고르는 단추를 눌러 바탕화면의 `my-first-app` 폴더를 선택합니다.
4. 입력창에 첫 지시를 보냅니다.

```text
안녕! 현재 폴더 상태를 확인해줘.
```

> [!OUTPUT]
> ```
> 현재 폴더(my-first-app)는 비어 있습니다.
> 무엇을 만들어 드릴까요?
> ```

> [!WARNING]
> Claude가 파일을 만들거나 고치기 전에 **허용할지 묻는 창**이 뜹니다. 무엇을 바꾸는지 읽어 본 뒤 허용하세요. 작업 폴더 밖의 파일은 건드리지 않도록 오늘 실습용 폴더만 선택하세요.

> [!NOTE]
> 메뉴 이름과 위치는 앱 버전에 따라 조금 다를 수 있습니다. 화면이 다르면 강사 화면을 따라 하세요.
