# 자연어로 웹페이지 만들기

> [!TIP]
> Claude Code에게 말로 설명해서 **자기소개 웹페이지**를 만듭니다. 생성된 파일 구조를 이해하고, 디자인을 업그레이드해 봅니다.

> [!CONCEPT] 웹 3대 핵심 기술
>
> - **HTML — 집의 뼈대**: 제목·문단·버튼·이미지를 배치합니다
> - **CSS — 집의 인테리어**: 색상·여백·글꼴·모바일 정렬을 맡습니다
> - **JavaScript — 집의 전기·장치**: 클릭 반응·계산·화면 전환을 맡습니다

## 태스크 1: 폴더와 파일 구조 이해하기

```text
my-profile-web/
├── index.html   ← 시작 문서: 브라우저로 열면 가장 먼저 보이는 파일
├── style.css    ← 디자인 파일: 글꼴·색상·배치·모바일 반응형
├── app.js       ← 동작 파일: 버튼 클릭·계산·알림
└── README.md    ← 설명서
```

## 태스크 2: 실습 D — 자기소개 웹페이지 생성

1. VS Code에서 새 폴더 `my-profile-web`을 열고 터미널에서 `claude`를 실행합니다.
2. 아래 프롬프트를 입력합니다.

```text
초보자를 위한 자기소개 웹페이지를 만들어주세요. 이름, 소개 문구, 관심 분야 3개와 연락하기 버튼을 포함해주세요. 반응형 디자인으로 만들고 실행 방법을 쉽게 설명해주세요.
```

3. 파일을 만들겠다고 물으면 내용을 확인하고 **허용(Yes)**합니다.

> [!SUCCESS]
> **생성 후 확인 사항**
> - **파일 생성**: 폴더 안에 `index.html`이 생겼나요?
> - **브라우저 실행**: `index.html`을 더블클릭하면 열리나요?
> - **반응형 확인**: 브라우저 창 크기를 줄였을 때 모바일 화면처럼 정렬되나요?

## 태스크 3: 디자인 바꾸기

같은 터미널에서 이어서 요청합니다.

```text
남색·주황 카드형으로 업그레이드해줘. 직함은 'AI 실무 크리에이터', 관심 분야는 해시태그 모양으로 바꾸고, 연락하기 버튼은 '이메일 보내기'로 바꿔줘.
```

| 구분 | BEFORE (기본 생성) | AFTER (업그레이드) |
|---|---|---|
| 제목 | 홍길동 | 홍길동 · AI 실무 크리에이터 |
| 소개 | AI를 배우는 직장인입니다. | 데이터와 AI로 일하는 방식을 혁신합니다. |
| 관심 분야 | 독서, 여행, 데이터 | #업무자동화 #데이터분석 #웹앱기획 |
| 버튼 | [연락하기] | [이메일 보내기] |
