# 기능 추가와 오류 수정

> [!TIP]
> 업무에 바로 쓰는 **매출·이익률 계산기**를 만들고, 일부러 버그를 넣은 계산기를 Claude Code로 고쳐 봅니다.

## 태스크 1: 웹앱 화면 설계하기

만들기 전에 화면에 무엇이 필요한지 정리합니다.

| 구성 | 내용 |
|---|---|
| 입력창 | 매출액(원), 총 비용(원) |
| 버튼 | 계산하기, 초기화 |
| 결과 | 순이익: 3,500,000원 \| 이익률: 35.0% |
| 설계 포인트 | 빈칸·음수 입력 시 안내 경고, 이익 = 매출 − 비용, 원클릭 초기화 |

## 태스크 2: 실습 E — 계산기 웹앱 만들기

바탕화면에 새 폴더 `profit-calculator`를 만들고, Code 탭에서 이 폴더를 작업 폴더로 고른 뒤 입력합니다.

```text
매출액과 비용을 입력하면 이익과 이익률을 계산하는 간단한 웹앱을 만들어주세요. 입력 검증, 계산 버튼, 결과 표시, 초기화 버튼을 포함해주세요. 먼저 로컬 환경에서 실행되도록 만들어주세요.
```

## 태스크 3: 테스트 시나리오 3종

| 시나리오 | 입력 | 기대 결과 |
|---|---|---|
| 정상 입력 | 매출 1,000,000 / 비용 700,000 | 이익률 **30.0%** |
| 예외 입력 | 매출 0원 또는 빈칸 | 안내 문구 표시 |
| 초기화 | 초기화 버튼 클릭 | 입력값·결과가 모두 지워짐 |

## 태스크 4: 디버깅 실습 — 버그 계산기 고치기

> [!DOWNLOAD]
> [calculator-buggy.zip](/files/week2/calculator-buggy.zip)
>
> **포함 파일:**
> - `index.html` - 계산기 화면
> - `style.css` - 디자인
> - `app.js` - 계산 로직 (매출 0원을 넣으면 NaN%가 나오는 버그가 있음)
>
> **사용 태스크:**
> - 태스크 4: 디버깅 실습

1. ZIP을 바탕화면에 풀고, Code 탭에서 **새 대화**를 열어 작업 폴더로 `calculator-buggy`를 선택합니다.
2. 폴더 안의 `index.html`을 더블클릭해 브라우저로 열고, 매출에 **0**을 넣고 계산해 봅니다.

> [!ERROR]
> 결과에 `순이익: 0원 | 이익률: NaN%`가 표시됩니다. 0으로 나누어서 생긴 오류입니다.

3. Code 대화창에 **증상을 그대로** 전달합니다.

```text
매출에 0원을 넣었더니 NaN%가 나와요. 0원일 때는 안내 문구가 뜨게 수정해줘.
```

4. 수정 내용을 확인하고 허용한 뒤, 브라우저를 **새로고침**해서 다시 테스트합니다.

| 단계 | 하는 일 |
|---|---|
| 01 오류 발견 | 잘못된 계산·화면 깨짐을 확인합니다 |
| 02 증상 전달 | 에러 문구와 상황을 그대로 입력합니다 |
| 03 자동 수정 | AI가 코드에서 원인을 찾아 고칩니다 |
| 04 재검증 | 새로고침 후 정상 동작을 확인합니다 |

> [!SUCCESS]
> 매출 0원에서 "매출액이 0원이면 이익률을 계산할 수 없습니다" 같은 안내가 나오고, 100만/70만 입력 시 30.0%가 나오면 성공입니다.
